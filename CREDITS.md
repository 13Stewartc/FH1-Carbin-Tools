# Credits & Acknowledgements

FH1-Carbin Tools is an independent community project developed to support vehicle modding, research and preservation for Forza Horizon (2012).

This project has benefited from existing research, community tools and documentation.

## Project Development

**13Stewartc (Stew)** — Project creator, development, research, testing and maintenance.

## Community Tools & Research

- **Forza Studio** — Vehicle model inspection, CARBIN structure investigation and export validation.
- **Forza Horizon Re-Imagined** — Recompiled game project used for testing modified vehicle assets in-game.
- **Blender Foundation** — Blender, the 3D modelling software used by this add-on.
